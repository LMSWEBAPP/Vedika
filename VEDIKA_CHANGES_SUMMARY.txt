1. DYNAMIC PRESENTATION ENGINE (FEATURE 1)
================================================================================
- Local System Presentation Folder Manager:
  * Vedika Desktop Pet now automatically initializes a standardized local system 
    directory on the user's PC:
    C:\Users\<Username>\Documents\VedikaPresentations\
  * Users can simply drop topic folders (e.g., "Product_Launch_2026", 
    "Physics_Viva_Demo") containing images (.png, .jpg, .webp, .svg), PDFs, and 
    notes directly into this system directory.
  * Vedika reads presentation assets directly from disk at 0ms latency with 
    zero cloud data store or cloud bandwidth overhead.
  * Primary File: engine/presentation_manager.py
  * API File: vedika/Vyomanta/frontend/app/api/presentation/folders/route.js

- Standalone Windows Executable (.exe) Packaging:
  * Created build_exe.py using PyInstaller to compile the Desktop Mascot into a 
    single standalone binary: dist/VedikaDesktopMascot.exe
  * Includes hidden imports for PySide6 GUI, QtMultimedia, QtWebSockets, and 
    google-genai.
  * Primary File: build_exe.py

- Two-Pass Real-Time AI Speech Operator:
  * Pass 1: Live speech teleprompter display using WebSpeech API.
  * Pass 2: Periodic 1.5s - 2s speech buffer sent to Gemini 2.5 Flash API to:
    1. Clean up presenter articulation stumbles, hesitations, and messy phrasing.
    2. Extract high-impact launch presentation elements: titles, subtitles, 
       bullet points, key takeaway cards, and highlight sentence banners.
    3. Match speech topics against images/documents in the local presentation folder.
  * API File: vedika/Vyomanta/frontend/app/api/presentation/route.js

- Tech-Giant Product Launch Event Stage Canvas:
  * Redesigned presentation stage with dark-mode glassmorphism, glowing ambient 
    lighting, animated bullet point lists, highlight callout banners, and 
    floating image cards.
  * Component File: vedika/Vyomanta/frontend/components/DynamicPresentation.jsx
