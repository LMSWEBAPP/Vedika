# shaders / point-cloud-simulation

A standalone PlayCanvas example, exported as a Vite project.

```bash
npm install
npm run dev
```

Then open the printed local URL.

The example's current control values are captured in `src/data.json` and applied after it loads.

> Depends on `playcanvas@latest` (the newest published release). This example was authored against `2.21.0`, so a newer release may behave slightly differently.
